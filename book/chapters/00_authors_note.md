# Author's Note {.unnumbered}

This is a work of fiction.

GeoCalc Pocket never existed. GeoStructure Systems was never a real company. The characters in this book—Dr. Margaret Chen, Bob Kuwahara, James Okoye, Sarah Martinez, Lisa Rodriguez, Kevin Park, Jennifer Wu, and all the others—are fictional.

The technology described is plausible and based on real Game Boy hardware specifications, real geological field methods, and real constraints of 1990s embedded systems development. But no one actually built a structural geology tool for the Nintendo Game Boy.

The author, "Kit Larson," is also a fictional persona created for this narrative.

This book is an exercise in speculative history: *What if someone had done this?* The story explores constraint-driven innovation, the intersection of consumer electronics and scientific instruments, and the culture of small engineering teams building niche products in the 1990s.

If you're a geologist who wishes GeoCalc Pocket had been real, I'm sorry. If you're a Game Boy enthusiast who thinks this would have been cool, I agree. If you're an engineer who enjoys stories about building things that work, this book is for you.

Everything that follows is made up.

But it could have happened.

— The Actual Author
